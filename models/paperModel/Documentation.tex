\unnumberedsection{PreProcessing}
The preprocessing pipeline includes:
\begin{itemize}
    \item Loading and organizing satellite images and their corresponding masks
    \item Converting GDAL datasets to NumPy arrays for processing
    \item Splitting the dataset into training (\%), validation (20\%), and test (20\%) sets.
    \item Applying random horizontal and vertical flips and random rotations to augment the dataset.
\end{itemize}


\unnumberedsection{Exploratory Data Analysis}

\begin{itemize}
    \item Dataset consists of 10,573 satellite images with corresponding\\
      cloud masks
    \item Images are in TIFF format with 4 spectral bands
    \item Masks are binary (cloud vs. no-cloud)
    \item Image dimensions: 512x512 pixels
    \item Data distribution:

    \begin{enumerate}
        \item Training: 6,343 images
        \item Validation: 2,115 images
        \item Test: 2,115 images
    \end{enumerate}

\end{itemize}

\unnumberedsection{Model Selection and Training Module}

\unnumberedsubsection{Model Architecture}
We implemented a U-Net architecture with:
\begin{itemize}
    \item Encoder-decoder structure with skip connections
    \item 5 levels of downsampling and upsampling
    \item Batch normalization and dropout for regularization
    \item Final sigmoid activation for binary classification
\end{itemize}

\unnumberedsubsection{Training Parameters}
\begin{itemize}
    \item Batch size: 16
    \item Learning rate: 0.001
    \item Number of epochs: 10
    \item Loss function: Cross Entropy Loss
    \item Optimizer: SGD
    \item Dropout probability: 0.1
\end{itemize}


\unnumberedsection{Performance Analysis Module}

\unnumberedsubsection{Evaluation Metrics}
\begin{itemize}
    \item Dice Coefficient: 0.8849 on test set
    \item Model has 7,764,353 parameters
    \item Approximately 1.48 trillion operations per forward pass
\end{itemize}

\unnumberedsubsection{Training Results}
The model showed consistent improvement during training:
\begin{itemize}
    \item Stable decrease in training loss
    \item Good generalization on validation set
    \item Final test performance indicates effective learning
\end{itemize}
