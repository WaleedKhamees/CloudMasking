\unnumberedsection{PreProcessing}
The preprocessing steps included:
\begin{itemize}
    \item Loading and processing satellite images and their corresponding masks from TIFF files
    \item Converting GDAL datasets to NumPy arrays for processing
    \item Splitting the dataset into training (76.5\%), validation (8.5\%), and test sets (15\%)
    \item Creating a custom PyTorch Dataset class to handle the satellite data
    \item Implementing data augmentation techniques (not shown in the notebook)
\end{itemize}

\unnumberedsection{Exploratory Data Analysis}
Key findings from the data exploration:
\begin{itemize}
    \item Dataset contains 10,573 image-mask pairs in total
    \item Images are 4-channel RGB + infrared with dimensions 512x512
    \item Masks are binary (cloud vs. non-cloud) with same dimensions
    \item Data was shuffled with a fixed random seed (42) for reproducibility
\end{itemize}

\unnumberedsection{Model Selection and Training Module}
The model architecture and training details:
\begin{itemize}
    \item Implemented a U-Net architecture with:
    \begin{itemize}
        \item 5 encoder blocks with increasing channels (32, 64, 128, 256, 512)
        \item Bottleneck layer with 1024 channels
        \item 5 decoder blocks with skip connections
        \item Final sigmoid activation for binary classification
    \end{itemize}
    \item Training parameters:
    \begin{itemize}
        \item Batch size: 16
        \item Learning rate: 0.001
        \item Optimizer: SGD
        \item Loss function: Binary Cross Entropy (BCELoss)
        \item Dropout probability: 0.5
        \item Number of epochs: 15
    \end{itemize}
    \item Performance metrics:
    \begin{itemize}
        \item Dice coefficient used for validation and testing
        \item Achieved validation accuracy of 87.78\% by final epoch
    \end{itemize}
\end{itemize}

\unnumberedsection{Performance Analysis Module}
Model performance results:
\begin{itemize}
    \item Final test Dice coefficient: 0.8789 (87.89\%)
    \item Model has 7,764,353 parameters
    \item Approximately 1.48 trillion operations per forward pass
    \item Training convergence:
    \begin{itemize}
        \item Started with train loss of 0.6471 (epoch 1)
        \item Improved to 0.3757 by final epoch
        \item Validation accuracy steadily increased from 76.69\% to 87.78\%
    \end{itemize}
\end{itemize}
